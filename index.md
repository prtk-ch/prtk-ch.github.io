I make computers talk and listen in the languages people here actually speak. Hindi, Marathi, Mauritian Creole. Most of the work runs on telephony audio, which is noisier and less forgiving than anything in a benchmark.

I build these systems end to end, and I run the GPU servers underneath them. I measure first, write down the dead ends, and keep a rollback one command away.

I'd rather report a bad result honestly than ship a good-looking number.
