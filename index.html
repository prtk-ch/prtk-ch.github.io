Build

Making TTS feel instant

Speech · vLLM · CUDA graphs

  • LLM-TTS time to first byte went from ~7 s to ~300 ms with vLLM streaming and CUDA graphs. Throughput was 205 tok/s, about 2.5× real time.
  • Mauritian Creole TTS first audio went from 5.15 s to 0.45 s. The fix was token-chunk streaming, CUDA-graph decode and a WebSocket buffering bug.
  • Fillers that play while the model thinks: ~4 ms to first sound, no training needed.

Voice cloning and a TTS platform

PyTorch · LoRA · FastAPI

  • Marathi voice clone shipped to production. LoRA took speaker similarity from 0.72 to 0.90.
  • Zero-training Hindi TTS (IndicF5, flow matching) scored CER 0.083 against a 0.200 pass floor. Emotion LoRA cut CER from 0.106 to 0.059.
  • Trained a GAN vocoder from scratch (120k steps). Render error fell from 18.0% to 12.5%.
  • Built an ElevenLabs-style platform around it: playground, hashed API keys, usage analytics, REST and WebSocket streaming. It replaced a paid vendor in our call-bot demos.

Speech-to-speech, no cascade

Gemma · Mimi codec · forced alignment

  • A Hindi model that goes audio in to audio out, Moshi-style, with first audio at ~64 ms.
  • Aligned 11.8k real Hindi calls into ~46k training pairs. Pretraining ran on 2,542 h of audio.
  • Found a never-trained embedding table and a broken WER harness (the floor was really 0.14, not 0.78). I caught several evals inflated ~3.5× by teacher forcing and moved the gates to free-run.

Serving a 12B model on half a GPU

vLLM · Gemma · supervisor

  • A pre-flight VRAM calculator that matches vLLM's allocator within ~2%, so a bad config fails in a second instead of after a three-minute load.
  • Sized the deployment from a load test: throughput flat past 32 concurrent requests, 42% peak KV, zero preemptions.
  • One-command idempotent installer, rsync fallback, tool-calling acceptance tests.

Alerts that don't cry wolf

Python · supervisor · Teams

  • A 30-second watchdog that asks the model for a real one-token completion, not just /health.
  • Events batched into one Teams card, with downtime and a root-cause line from the engine log.
  • Traced missed morning starts to a stray process holding 95 GB of VRAM.

Audio-in call-flow engine

Architecture · design stage

  • Picks the next node of a collections call straight from audio, with no STT. Models choose intents; the graph chooses destinations.
  • Today's baseline is ~1,540 tokens and 2 LLM calls per turn. The target is 0.15–0.25 calls per turn, in six gated phases.
  • Rejected a non-commercial encoder for shipping on licence grounds.

Data engineering

PostgreSQL · Kafka · Spark · dbt · GCP

  • On-prem PostgreSQL migration: tuned for OLTP, pgBouncer pooling, per-tenant quotas. ~40% lower infra cost and ~90% faster API responses.
  • Real-Time Margin and Collateral Engine: Kafka to GCS to BigQuery with Spark, 10M+ daily records, sub-second latency, zero loss. dbt models cut ad-hoc query time ~70%.
  • Voice bots on Python WebSockets, Google STT/TTS and Gemini, with a Go Asterisk integration. 500+ calls a day.
  • RAG on pgvector that cut manual query-resolution time ~60%.
